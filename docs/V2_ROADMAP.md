# InsightFlow AI V2 Roadmap

This is future work. None of these items should be represented as implemented V1 functionality.

## Candidate areas
1. Authentication and authorization
2. Additional data sources and multi-dataset analysis
3. More advanced analytics and visualizations
4. Broader evaluation datasets and regression measures
5. Observability and tracing
6. Deployment and scalability
7. A migration system for schema evolution
8. Additional AI capabilities within the existing controlled-tool boundary

## Principles
Keep numerical calculations deterministic. Preserve validation and grounding.
Do not enable unrestricted Python or SQL execution. Prioritize work based on
measured V1 limitations and user needs.
