## Known operation boundary

V2.2 remains the authoritative operation definition. The V2.2 metadata does not define safe semantics for every operation detail. V2.3 returns structured failures for underdefined filter predicates, formula evaluation, aggregate function vocabulary, `count(column)` value/null behavior, missing-value grouping/sort/distinct behavior, tied ranking, percentage-difference denominator convention, and group-comparison semantics. No inference or arbitrary expression execution is used.
